# 🦺 Safety Checklist

PWA offline-first per la digitalizzazione delle checklist HSE.

- 📄 **PROJECT.md** → specifiche complete (architettura, UX, schema dati). Fonte di verità per lo sviluppo.
- 📋 **TASKS.md** → roadmap in 9 fasi, con prompt pronti da dare a Claude Code, fase per fase.
- 📑 **checklists/people_design.json** → esempio di checklist in formato JSON (schema documentato in PROJECT.md §5).

## Come procedere

1. Apri questo repository con Claude Code.
2. Dagli in pasto `PROJECT.md` come contesto.
3. Segui `TASKS.md` una fase alla volta, copiando i prompt suggeriti.
4. Testa su telefono dopo ogni fase, prima di passare alla successiva.

Nessuna dipendenza a pagamento. Nessun backend richiesto per la v1.0.
